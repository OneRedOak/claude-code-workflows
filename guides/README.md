# Companion guides

Free playbooks to accompany [Patrick Ellis' videos](https://www.youtube.com/@PatrickOakleyEllis), with downloadable PDFs, clickable resources, and copyable examples.

| Guide | What you'll build | Edition |
| --- | --- | --- |
| [The Orchestration Layer Playbook](./orchestration-layer/) | Context, tools, workflows, and verification for Claude Code and Codex | 1.2 · October 6, 2026 |

Each guide has its own folder. Start with its overview, download the PDF for offline reading, and use its resource list for clickable links. You do not need to clone this repository or create a GitHub account to download a guide.

## Editions and updates

PDF filenames stay stable so links continue to work. Each guide's overview records its edition, revision date, and changes. Tool capabilities may change independently of the guide; consult the linked official documentation when implementing a workflow.

New guides should follow the same structure: `README.md`, a descriptively named PDF, `resources.md`, and a `templates/` folder when there are useful examples to copy. Keep video files and production assets outside this repository.
